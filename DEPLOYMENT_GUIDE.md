## 🍃 2. MongoDB Database Configuration

The application supports MongoDB connections out-of-the-box using Prisma ORM.

### Steps to Connect MongoDB:
1. In `codebase/backend/.env`, update `DATABASE_URL`:
   ```env
   DATABASE_URL="mongodb+srv://<username>:<password>@cluster0.mongodb.net/winnify_db?retryWrites=true&w=majority"
   ```
2. Apply the MongoDB schema:
   ```bash
   cd codebase
   cp prisma/schema.mongodb.prisma prisma/schema.prisma
   npx prisma db push
   ```

## 🚀 3. Deploying Backend to Render

The repository includes a ready-to-use [`render.yaml`](file:///c:/Users/LENOVO/OneDrive/Desktop/SkillSprint_Data/render.yaml) specification.

### Render Setup:
1. Go to [Render Dashboard](https://dashboard.render.com/) and click **New + -> Blueprint**.
2. Connect your Git repository. Render will automatically detect `render.yaml`.
3. Fill in Environment Variables:
   - `DATABASE_URL`: Your MongoDB Atlas connection string.
   - `JWT_SECRET`: Random secure string (autogenerated by Render).
   - `OPENAI_API_KEY`: (Optional) Your OpenAI API key for live GPT-4o analysis.
4. Render will run:
   - **Build**: `cd codebase/backend && npm install && npm run build`
   - **Start**: `cd codebase/backend && npm start`

## 🐙 4. Deploying Frontend to GitHub Pages

The repository contains a GitHub Actions workflow at [deploy-frontend.yml](file:///c:/Users/LENOVO/OneDrive/Desktop/SkillSprint_Data/.github/workflows/deploy-frontend.yml).

### GitHub Setup:
1. Push your project repository to GitHub:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/winnify-platform.git
   git push -u origin master
   ```
2. On GitHub, navigate to **Settings -> Pages**.
3. Set **Source** to **GitHub Actions**.
4. Every push to `master` / `main` will automatically build the Vite React application and deploy it live to `https://YOUR_USERNAME.github.io/winnify-platform/`!
